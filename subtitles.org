subtitles --- a GNU shell script that turns a film's dubbed audio track
              (Japanese by default) into proper subtitles of what is
              actually said, using a local Whisper model on the GPU,
              guided by an existing but textually wrong subtitle file
              whose timings are good (a translation track, an OCR of a
              bitmap track, an auto-generated track, …).

Copyright (C) 2026 白い熊

Author: 白い熊

** Why
A disc's Japanese subtitle track is a translation of the *original*
dialogue — it is not what the Japanese dub says.  OCR of such a track
gives good cue timings and useless text.  This tool keeps the timings
as a map of where speech is, transcribes the dub with Whisper, and
builds subtitles from the dub's own word timestamps.

** Pipeline
1. Decode the audio to 16 kHz mono WAV (=ffmpeg=, any container).
2. Speech regions: the reference SRT's cues, padded 0.4 s before and
   0.6 s after and merged across gaps of ≤ 1 s, united with anything
   a VAD (Silero) hears outside them.  Without a reference SRT the VAD
   alone defines the regions.  Regions longer than 60 s are split at
   their largest internal gap.
3. Whisper large-v3, per region, with word timestamps — *twice*: once
   with a prompt of character names (better spellings), once without.
   The prompt makes Whisper occasionally emit the prompt text instead
   of the audio, so the two passes are merged region by region: the
   prompted result only where it is hallucination-free and covers the
   VAD speech at least as well as the unprompted one.
4. Filters: prompt echoes, the classic YouTube-outro hallucinations
   (「ご視聴ありがとうございました」, "Thanks for watching"), repetition
   loops, no-speech segments.  Name variants are normalised.
5. Subtitle lines from word timestamps: cut at sentence ends, pauses
   ≥ 0.7 s, the reference cue boundaries and a length cap; starts and
   ends snapped to reference cues when within 0.3 s; ≥ 1.2 s on screen,
   ≤ 2 lines (16 characters for Japanese, 42 for Latin scripts);
   trailing 。 removed for Japanese.
6. Checks: VAD speech left without a line, the lowest-confidence lines,
   written to a review report beside the SRT.

** Lessons baked in (from the first use, The Thin Red Line, 2026-09-16)
- The reference SRT and the audio *must be on the same timeline*; a
  Blu-ray with a longer head shifts everything (there it was 10.823 s).
  Check the first cue against the first line of dialogue before running.
- A raw =.aac= extracted from an MKV decodes with its 1024-sample
  priming in place, so it is timeline-correct as a standalone file.
- A bitmap (PGS) subtitle track needs no OCR to serve as the timing
  reference: its packets are "show" (large, with a duration) and
  "clear" (≈30 bytes) display sets, which is all a cue map needs.
- Two passes are not optional: with the prompt alone 12 of 32 minutes
  of speech came out as prompt echo; without it names drift
  (ウイット/ウィット).  Merged: 0.2 minutes uncovered.
- Whisper's Japanese has ordinary homophone slips (階級賞/階級章,
  軍装/軍曹); the result is proofreading material, not a final text.

** Usage
#+begin_example
subtitles.sh [options] INPUT            INPUT: any audio or video file ffmpeg reads
  -h            this help
  -p            PROBE: run every probe and print a verdict per option — green
                when the current value is right, yellow for a suggestion, red
                when a change is needed — plus the ready-made next command
  -P WHAT       one probe only: streams|timeline|regions|language|models|names
  -l LANG       language of the dub (default ja)
  -r REF.srt    reference subtitles with usable timings (default: the fullest
                subtitle track inside INPUT, PGS or text; "-r none" for VAD only)
  -s SECONDS    shift REF.srt by this much before use (default 0)
  -n NAMES      character names for the prompt, comma-separated (default none:
                single unprompted pass); a name may carry variants: 正=誤1|誤2
  -m MODEL      Whisper model (default large-v3)
  -a N          audio stream index inside a container (default: the first
                stream tagged with LANG, else 0)
  -o OUT.srt    output (default INPUT-basename.LANG.srt beside the input)
  -w DIR        work dir with the cache (default /tmp/subtitles/BASENAME)
  -f            force re-transcription, ignore cached passes
  -M            update the input MKV in place: the SRT goes in before the
                first subtitle track of LANG (text before bitmap), after all
                subtitles when there is none; verified before replacing; the
                SRT and the review then move into the work dir (nothing is
                left beside the movie)
  -S N          sample regions for the probes (default 12)
  -L MODELS     models tried by the models probe (default turbo,large-v3,medium)

The simple workflow: run once with =-p=, read the verdict, then run
once more without =-p= — with the options the verdict recommended, if
any.  Every pass shows "region xx/XXX" with elapsed and remaining time.
With an MKV as input nothing else is needed: the audio stream tagged
with the dub language and the fullest subtitle track (a bitmap PGS
track serves as well — only its timings are read) are picked and
listed, each marked "this one will be used".

PAD_BEFORE, PAD_AFTER, MERGE_GAP, MAX_REGION = 0.4, 0.6, 1.0, 60.0

*** SRT reading and writing
**** Time codes
#+begin_src python
def srt_time(s):
    h, m, rest = s.strip().split(":"); sec, ms = rest.split(",")
    return int(h)*3600 + int(m)*60 + int(sec) + int(ms)/1000

def fmt_time(t):
    ms = max(0, int(round(t*1000)))
    return "%02d:%02d:%02d,%03d" % (ms//3600000, (ms//60000) % 60, (ms//1000) % 60, ms % 1000)

def hms(s): return "%d:%02d:%05.2f" % (s//3600, (s % 3600)//60, s % 60)
#+end_src
**** Files
Positioning tags such as ={\an8}= are dropped on reading; =shift= moves
every cue (positive = later), which is how a reference on another
timeline is brought onto the audio's.
#+begin_src python
def read_srt(path, shift=0.0):
    """-> list of (start, end, text)"""
    txt = open(path, encoding="utf-8-sig", errors="replace").read()
    out = []
    for b in re.split(r"\n\s*\n", txt.strip()):
        lines = b.strip().split("\n")
        if len(lines) < 2 or "-->" not in lines[1]: continue
        a, c = lines[1].split("-->")
        text = re.sub(r"\{\\an\d\}", "", "\n".join(lines[2:])).strip()
        out.append((srt_time(a)+shift, srt_time(c)+shift, text))
    return [c for c in out if c[1] > 0]

def write_srt(path, cues):
    with open(path, "w", encoding="utf-8") as f:
        f.write("\n".join("%d\n%s --> %s\n%s\n" % (i, fmt_time(s), fmt_time(e), t)
                          for i, (s, e, t) in enumerate(cues, 1)))
#+end_src
*** Speech regions
**** Voice activity detection
Silero VAD over the whole track, once, cached in the work dir.
#+begin_src python
def run_vad(x, sr, cache):
    if os.path.exists(cache): return json.load(open(cache))
    import torch
    from silero_vad import load_silero_vad, get_speech_timestamps
    model = load_silero_vad(onnx=False)
    ts = get_speech_timestamps(torch.from_numpy(x), model, sampling_rate=sr, threshold=0.5,
                               min_speech_duration_ms=250, min_silence_duration_ms=300, speech_pad_ms=100)
    vad = [(d["start"]/sr, d["end"]/sr) for d in ts]
    json.dump(vad, open(cache, "w"))

**** Region assembly
The padded reference cues, plus VAD speech that no padded cue covers,
merged across gaps of ≤ =MERGE_GAP=.  Without cues the VAD alone.
#+begin_src python
def outside_cues(cues, vad, total):
    cov = np.zeros(int(total)+2)
    for s, e, _ in cues: cov[max(0, int(s-PAD_BEFORE)):int(e+PAD_AFTER)+1] = 1
    return [(s, e) for s, e in vad if cov[int(s)] == 0 and cov[int(e)] == 0 and e-s >= VAD_MIN_OUTSIDE]

def build_regions(cues, vad, total):
    iv = [(max(0, s-PAD_BEFORE), min(total, e+PAD_AFTER)) for s, e, _ in cues]
    iv += [(max(0, s-0.3), min(total, e+0.3)) for s, e in outside_cues(cues, vad, total)]
    iv.sort(); regions = []
    for s, e in iv:
        if regions and s - regions[-1][1] <= MERGE_GAP: regions[-1][1] = max(regions[-1][1], e)
        else: regions.append([s, e])
    return [r for reg in regions for r in split_long(reg, cues, vad)]
#+end_src
**** Splitting long regions
Whisper works in 30-s windows; a region longer than =MAX_REGION= is cut
at its largest internal gap between cues (or VAD chunks).
#+begin_src python
def split_long(r, cues, vad):
    s, e = r
    if e-s <= MAX_REGION: return [r]
    inner = sorted(c[:2] for c in cues if s < c[0] and c[1] < e) or sorted(v for v in vad if s < v[0] and v[1] < e)
    gaps = [(inner[i+1][0]-inner[i][1], (inner[i][1]+inner[i+1][0])/2) for i in range(len(inner)-1)]
    if not gaps: return [r]
    g, m = max(gaps)
    return split_long([s, m], cues, vad) + split_long([m, e], cues, vad)

#+begin_src python
def mmss(t): return "%d:%02d" % (t//60, t % 60)

class Progress:
    def __init__(self, label, total):
        self.label, self.total, self.t0 = label, total, time.time(); self.tty = sys.stdout.isatty()
    def step(self, i, extra=""):
        el = time.time()-self.t0; rem = el/(i)*(self.total-i) if i else 0
        line = "  %s %*d/%d  elapsed %s  remaining ~%s  %s" % (self.label, len(str(self.total)), i, self.total, mmss(el), mmss(rem), extra)
        if self.tty: print("\r" + line + " "*8, end="", flush=True)
        elif i % 25 == 0 or i == self.total: print(line, flush=True)
    def done(self):
        if self.tty: print(flush=True)

**** One pass over regions
One Whisper call per region; the region's start is added back to every
segment and word time.  The result is cached per pass so that the
subtitle-building parameters can be re-tuned without re-transcribing.
#+begin_src python
def transcribe(x, sr, regions, lang, model_name, prompt, cache=None, force=False, model=None, label="regions"):
    if cache and os.path.exists(cache) and not force:
        print("  %s: cached (%s)" % (label, os.path.basename(cache))); return json.load(open(cache))
    own = model is None
    if own: model = load_model(model_name)
    out = []; prog = Progress(label, len(regions))
    for k, (s, e) in enumerate(regions):
        r = model.transcribe(x[int(s*sr):int(e*sr)], language=lang, task="transcribe",
                             word_timestamps=True, initial_prompt=prompt,
                             condition_on_previous_text=False, fp16=True, beam_size=5, best_of=5)
        for seg in r["segments"]:
            out.append(dict(region=k, start=s+seg["start"], end=s+seg["end"], text=seg["text"],
                            avg_logprob=seg["avg_logprob"], no_speech_prob=seg["no_speech_prob"],
                            compression_ratio=seg["compression_ratio"],
                            words=[dict(w=w["word"], start=s+w["start"], end=s+w["end"], p=w.get("probability", 0))
                                   for w in seg.get("words", [])]))
        prog.step(k+1, "at %s, %d segments" % (hms(s), len(out)))
        if cache and (k % 25 == 0): json.dump(out, open(cache, "w"), ensure_ascii=False)
    prog.done()
    if cache: json.dump(out, open(cache, "w"), ensure_ascii=False)
    if own: unload_model(model)
    return out
#+end_src
*** Hallucination filter
A segment is dropped when Whisper itself flags it (no speech, or a
repetition loop), when it is a known outro phrase, or when it echoes
the name prompt (as a whole or by 4-gram overlap).
#+begin_src python
def strip_punct(t): return re.sub(r"[、。！？!?，,.\s『』「」\"']", "", t)

def bad_reason(seg, cfg, prompt):
    t = seg["text"].strip()
    if seg["no_speech_prob"] > 0.6 and seg["avg_logprob"] < -1.0: return "no-speech"
    if seg["compression_ratio"] > 2.4: return "repetition"
    if not t or not re.search(r"\w", t): return "empty"
    if any(h.lower() in t.lower() for h in cfg["hallu"]): return "hallucination"
    if prompt:
        ts_, ps = strip_punct(t), strip_punct(prompt)
        if len(ts_) >= 6 and ts_ in ps: return "prompt-echo"
        if len(ts_) >= 6 and sum(1 for i in range(len(ts_)-3) if ts_[i:i+4] in ps)/(len(ts_)-3) > 0.7: return "prompt-echo"
    return None
#+end_src
*** Merging the two passes
**** Coverage of VAD speech
How much of the VAD speech inside a region the segments cover.
#+begin_src python
def coverage(segs, rs, re_, vad):
    cov = np.zeros(int((re_-rs)*20)+2)
    for s in segs: cov[max(0, int((s["start"]-rs)*20)):int((s["end"]-rs)*20)+1] = 1
    tot = hit = 0
    for s, e in vad:
        if e <= rs or s >= re_: continue
        s, e = max(s, rs), min(e, re_); n = int((e-s)*20)
        if n <= 0: continue
        tot += n; hit += cov[int((s-rs)*20):int((s-rs)*20)+n].sum()
    return hit/tot if tot else 1.0
#+end_src
**** Merge and name normalisation
For every region the prompted pass wins only when it has no dropped
segment and covers the VAD speech at least as well as the unprompted
pass; otherwise the unprompted pass is used.  Then the name variants
are replaced by their canonical spelling.
#+begin_src python
def merge_passes(A, B, regions, vad, cfg, prompt, names):
    out = []; used = dict(prompt=0, noprompt=0); dropped = []
    for k, (rs, re_) in enumerate(regions):
        a = [s for s in (A or []) if s["region"] == k]; b = [s for s in B if s["region"] == k]
        a_ok = [s for s in a if not bad_reason(s, cfg, prompt)]
        b_ok = [s for s in b if not bad_reason(s, cfg, None)]
        dropped += [(s, bad_reason(s, cfg, prompt)) for s in a if bad_reason(s, cfg, prompt)]
        dropped += [(s, bad_reason(s, cfg, None)) for s in b if bad_reason(s, cfg, None)]
        if A is not None and len(a_ok) == len(a) and coverage(a_ok, rs, re_, vad) >= coverage(b_ok, rs, re_, vad) - 0.05:
            out += a_ok; used["prompt"] += 1
        else:
            out += b_ok; used["noprompt"] += 1
    out.sort(key=lambda s: s["start"])
    for canon, variants in names.items():
        for v in variants:
            for s in out:
                if v in s["text"]:
                    s["text"] = s["text"].replace(v, canon)
                    for w in s["words"]: w["w"] = w["w"].replace(v, canon)
    return out, used, dropped
#+end_src
*** Subtitle building
**** Units from word timestamps
A unit ends at sentence punctuation, at a pause ≥ =PAUSE_SPLIT=, at a
reference cue boundary that falls between two words, or when the text
or duration cap is reached.
#+begin_src python
def make_units(segs, cues, cfg):
    cue_ends = sorted(c[1] for c in cues); maxchars = 2*cfg["maxline"]
    units = []
    for seg in segs:
        ws = [w for w in seg["words"] if w["w"].strip()] or [dict(w=seg["text"].strip(), start=seg["start"], end=seg["end"], p=0.5)]
        cur = []
        for k, w in enumerate(ws):
            cur.append(w)
            text = "".join(x["w"] for x in cur).strip()
            nxt = ws[k+1] if k+1 < len(ws) else None
            end_sentence = bool(re.search("[" + re.escape(cfg["punct_end"]) + "]$", w["w"].strip()))
            gap = (nxt["start"] - w["end"]) if nxt else 9
            i = bisect.bisect_left(cue_ends, w["end"]-0.05)
            at_boundary = nxt is not None and i < len(cue_ends) and cue_ends[i] <= nxt["start"]+0.05
            too_long = len(text) >= maxchars or (cur[-1]["end"]-cur[0]["start"]) >= MAX_DUR
            if end_sentence or gap >= PAUSE_SPLIT or at_boundary or too_long or nxt is None:
                units.append(dict(words=list(cur), logprob=seg["avg_logprob"])); cur = []
    return units
#+end_src
**** Snapping to reference cues
#+begin_src python
def nearest(t, arr):
    i = bisect.bisect_left(arr, t); best = None
    for j in (i-1, i):
        if 0 <= j < len(arr) and abs(arr[j]-t) <= SNAP and (best is None or abs(arr[j]-t) < abs(best-t)): best = arr[j]
    return best

**** Line breaking
Two lines at most.  Latin scripts break at a space near the middle,
preferring one after punctuation; Japanese breaks near the middle,
preferring after punctuation, then after a particle.
#+begin_src python
def break_lines(t, cfg):
    t = t.strip(); n = cfg["maxline"]
    if len(t) <= n: return t
    if cfg["spaces"]:
        words = t.split(); best = None
        for i in range(1, len(words)):
            a, b = " ".join(words[:i]), " ".join(words[i:])
            score = abs(len(a)-len(b)) + (0 if re.search(r"[,.;:!?]$", a) else 4)
            if best is None or score < best[0]: best = (score, a + "\n" + b)
        return best[1]
    best = None; mid = len(t)/2
    for i in range(6, len(t)-5):
        ch = t[i-1]
        score = abs(i-mid) + (0 if ch in "、。，！？" else (3 if ch in "はがをにでとへもの" else 8))
        if best is None or score < best[0]: best = (score, i)
    i = best[1] if best else int(mid)
    return t[:i] + "\n" + t[i:]

def build_cues(units, cues, cfg):
    starts = sorted(c[0] for c in cues); ends = sorted(c[1] for c in cues); out = []
    for u in units:
        ws = u["words"]
        text = "".join(w["w"] for w in ws).strip()
        text = re.sub(r"\s+", " " if cfg["spaces"] else "", text)
        if cfg["strip_end"]: text = re.sub("[" + re.escape(cfg["strip_end"]) + "]+$", "", text)
        st, en = max(0.0, ws[0]["start"]-LEAD), ws[-1]["end"]+LINGER
        s2, e2 = nearest(ws[0]["start"], starts), nearest(ws[-1]["end"], ends)
        if s2 is not None and s2 <= ws[0]["start"]+0.05: st = s2
        if e2 is not None and e2 >= ws[-1]["end"]-0.05: en = e2
        if en-st < MIN_DUR: en = st + MIN_DUR
        out.append(dict(start=st, end=en, text=text, logprob=u["logprob"]))
    out.sort(key=lambda c: c["start"])
    merged = []
    for c in out:
        if merged and len(c["text"]) <= 3 and c["start"]-merged[-1]["end"] < 0.4 and len(merged[-1]["text"])+len(c["text"]) <= 2*cfg["maxline"]:
            merged[-1]["text"] += ("" if not cfg["spaces"] else " ") + c["text"]; merged[-1]["end"] = max(merged[-1]["end"], c["end"]); continue
        merged.append(c)
    for a, b in zip(merged, merged[1:]):
        if a["end"] > b["start"]-GAP: a["end"] = max(a["start"]+0.5, b["start"]-GAP)
    return [(c["start"], c["end"], break_lines(c["text"], cfg), c["logprob"]) for c in merged]

def scan_subtitle_cues(path):
    import subprocess
    out = subprocess.run(["ffprobe", "-v", "error", "-select_streams", "s", "-show_entries",
                          "packet=stream_index,pts_time,duration_time,size", "-of", "csv=p=0", path],
                         capture_output=True, text=True).stdout
    pk = {}
    for line in out.splitlines():
        f = line.split(",")
        if len(f) < 4 or f[1] in ("N/A", ""): continue
        pk.setdefault(int(f[0]), []).append((float(f[1]), None if f[2] in ("N/A", "") else float(f[2]), int(f[3])))
    cues = {}
    for idx, lst in pk.items():
        lst.sort(); c = []
        for i, (t, d, size) in enumerate(lst):
            if size <= 200 and d is None: continue                       # PGS clear set
            nxt = lst[i+1][0] if i+1 < len(lst) else t + 3.0
            end = t + d if d else nxt
            if end > nxt: end = nxt
            if end - t >= 0.2: c.append((t, end))
        cues[idx] = c
    return cues

#+begin_src python
def probe_timeline(cues, vad, total):
    """-> offset in seconds, or None without a reference"""
    if not cues: print("timeline: no reference SRT given (-r)"); return None
    n = int(total*10)+1; a = np.zeros(n); b = np.zeros(n)
    for s, e, _ in cues: a[int(s*10):int(e*10)+1] = 1
    for s, e in vad: b[int(s*10):int(e*10)+1] = 1
    a -= a.mean(); b -= b.mean()
    from scipy.signal import fftconvolve
    corr = fftconvolve(b, a[::-1], mode="full")            # index n-1 <-> lag 0
    lags = np.arange(-n+1, n)/10.0; sel = np.abs(lags) <= 180
    c = corr[sel]; l = lags[sel]; i = int(np.argmax(c)); peak = c[i]/(np.sqrt((a**2).sum()*(b**2).sum())+1e-9)
    print("timeline: best offset (audio speech minus reference cues) = %+.1f s, correlation %.2f" % (l[i], peak))
    print("          first cue %s, first VAD speech %s" % (hms(cues[0][0]), hms(vad[0][0]) if vad else "-"))
    if abs(l[i]) >= 0.3: print("          -> the reference is on another timeline: use  -s %+.1f" % l[i])
    else: print("          -> same timeline, no -s needed")
    return float(l[i])

def parse_names(spec):
    """'正=誤1|誤2,名前' -> {canonical: [variants]}"""
    names = {}
    for item in [x.strip() for x in (spec or "").split(",") if x.strip()]:
        canon, _, vars_ = item.partition("=")
        names[canon.strip()] = [v.strip() for v in vars_.split("|") if v.strip()]
    return names

help() {

Usage: subtitles.sh [options] INPUT
       subtitles.sh -p [options] INPUT

said, with a local Whisper model on the GPU.  An existing subtitle file
whose timings are right but whose text is not (a translation track, an OCR
of a bitmap track) serves as the map of where speech is; the subtitles are
built from the dub's own word timestamps and snapped to those cues.

The simple workflow is two commands: first with -p, which probes the file
and prints a verdict per option — green when the value in force (default or
